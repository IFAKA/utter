How typing works

4 tokens pick letter groups (abcdef · ghijklm · nopqrs · tuvwxyz), like T9. na = next suggestion, ya = accept, sha = back, ree = wake/pause. With no letters, the local LLM suggests the next word, so most words are a single "ya". The earbud quietly says the current suggestion, so you never need to look.
